### Accents with US International Keyboard (Dead Keys)

| To Type | Press Dead Key + Key | Result |
|---------|----------------------|--------|
| á       | `'` then `a`         | á      |
| é       | `'` then `e`         | é      |
| í       | `'` then `i`         | í      |
| ó       | `'` then `o`         | ó      |
| ú       | `'` then `u`         | ú      |
| ñ       | `~` then `n`         | ñ      |
| ü       | `"` then `u`         | ü      |
| â       | `^` then `a`         | â      |
| ê       | `^` then `e`         | ê      |
| ô       | `^` then `o`         | ô      |
| à       | `` ` `` then `a`     | à      |
| ç       | `Right-Alt + ,` then `c` (or `AltGr + ,` then `c`) | ç      |


### Typing the Dead Keys Themselves

To type the dead key characters by themselves, press the key followed by the spacebar:

| Character | Key + Space |
|-----------|-------------|
| `'`       | `'` then Space |
| `"`       | `"` then Space |
| `~`       | `~` then Space |
| `^`       | `^` then Space |
| `` ` ``   | `` ` `` then Space |

### Extra Special Characters (Using Right Alt / AltGr)

| To Type | Press            | Result |
|---------|------------------|--------|
| €       | `Right Alt + e`  | €      |
| ©       | `Right Alt + c`  | ©      |
| ®       | `Right Alt + r`  | ®      |
| ß       | `Right Alt + s`  | ß      |
| ¿       | `Right Alt + /`  | ¿      |
| ¡       | `Right Alt + 1`  | ¡      |
